# CWA (Create Web API)

A simple console application for creating web APIs with a frontend and database.

---

## Installation
1. Download the [latest release](https://github.com/BonitoCat/Create-Web-Api/releases/latest) of 'CWA' for your OS.
2. Extract the binary and place it in a folder accessible via your terminal (or add it to your system PATH).
3. Run the binary and follow the interactive setup instructions.
